TextSnap

Capture text from anywhere on your screen with one shortcut. Recognized locally. No internet required.

⬇ Download for Mac View on GitHub →

Free · Open Source · macOS 14.0+ · Apple Silicon & Intel

How it works

Three steps to any text

No setup, no configuration. Just press the shortcut and select.

1

Press the shortcut

Hit ⌘⇧2 from any app to activate capture mode.

2

Select a region

Draw a rectangle over any text visible on screen.

3

Paste anywhere

Text is recognized and copied. Press ⌘V to paste.

Features

Everything you need, nothing you don't

🔍

Local OCR

Uses Apple Vision framework. Your screenshots never leave your Mac.

🇯🇵 🇺🇸

Japanese & English

Recognizes both languages individually or mixed in the same image.

🖥

Multi-display

Supports multiple monitors with different Retina scale factors.

⚡

Instant capture

No streaming, no delay. A single screenshot is taken and discarded after recognition.

📋

Plain text output

Result is always plain text — paste cleanly into any app.

🔇

Menu bar only

No Dock icon, no windows, no clutter. Runs quietly in the background.

🔒 Privacy first

TextSnap processes screenshots and recognized text locally on your Mac. It does not upload, store, or transmit captured images or OCR results.

  • ✓ No network requests — ever
  • ✓ No account or sign-in required
  • ✓ Screenshots are never written to disk
  • ✓ No analytics or telemetry
  • ✓ 100% open source — audit the code
